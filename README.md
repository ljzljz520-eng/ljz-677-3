# 体检结果批量上传

工作人员导入 Excel（人员编号/项目/结果/单位/体检日期），后端校验后上送健康平台，
平台返回异常按行展示。支持任务进度、重复识别、异常导出与失败重试。

## 运行

```bash
pip install -r requirements.txt
python3 app.py          # 访问 http://localhost:5000
python3 make_sample.py  # 生成测试数据 sample.xlsx
```

## 功能

- **Excel 导入**：.xlsx，表头需含 人员编号/项目/结果/体检日期（单位选填），支持拖拽上传
- **后端校验**：必填项、人员编号格式、日期格式与合理性（不晚于今天、不早于2000年）
- **重复识别**：人员编号+项目+体检日期相同即判重（文件内 + 历史已上传记录），重复行不上送
- **任务进度**：后台线程逐行处理，前端轮询展示进度条与成功/失败/重复计数
- **异常按行展示**：明细页可按 全部/成功/失败/重复 筛选，平台退回原因逐行展示
- **异常导出**：一键导出失败+重复行为 Excel（含异常类型与原因）
- **失败重试**：仅重试被平台退回的行，校验失败与重复行不受影响

## 模拟健康平台

`platform_upload()` 为模拟实现（真实环境替换为 HTTP 调用），退回规则：

| 数据特征 | 平台返回 |
|---|---|
| 人员编号含 `404` | 人员不存在 |
| 项目不在平台目录 | 项目未在平台目录中 |
| 结果含 `ERR` | 结果格式不被接受 |

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/upload` | 上传 Excel，创建任务 |
| GET | `/api/tasks` | 任务列表（含进度） |
| GET | `/api/tasks/<id>/rows?status=&page=` | 行明细 |
| GET | `/api/tasks/<id>/export` | 导出异常 Excel |
| POST | `/api/tasks/<id>/retry` | 重试平台退回行 |
| GET | `/api/template` | 下载导入模板 |
